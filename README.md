# Cresponchilas site

Public site for Cresponchilas games, served by GitHub Pages at https://nicolasgomezecheverri.github.io/

- `index.html`: studio page
- `shove-blocks/privacy/`: Shove Blocks privacy policy (the URL given to Google Play)
- `app-ads.txt`: must stay at the site root; it lists the AdMob publisher ID that may sell ads in our apps

The source code of the games lives in private repositories.
